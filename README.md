# BITRICH

> **Still a joke. Please don’t give random strangers your money.**

This repository now ships with a modern Flask 3 stack, first-party user
management, and a light-weight investment simulator so you can demo the BitRich
concept without vintage dependencies or deprecated APIs.

## What’s New

- Flask 3, Flask-Login 0.6, and Flask-SQLAlchemy 3 for an all-Python auth stack
- SQLite-backed user + investment models with live BTC price lookups
- CLI tooling via `flask check-investments` or `python manage.py sell_or_not`
- `.env`-driven configuration with a helper bootstrap script

## Requirements

- Python 3.11+
- pip / virtualenv (or your favorite environment manager)

## Quick Start

```bash
git clone https://github.com/rdegges/bitrich-www.git
cd bitrich-www
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python bootstrap.py          # creates .env with a SECRET_KEY
flask --app app run          # or python app.py
```

Visit <http://localhost:5000> and register a user account to start “investing”.

## Configuration

Environment variables (load from `.env` or your shell):

| Name | Description | Default |
| --- | --- | --- |
| `SECRET_KEY` | Flask session key | generated by `bootstrap.py` |
| `DATABASE_URL` | SQLAlchemy database URI | `sqlite:///bitrich.db` |
| `EXCHANGE_RATE_URL` | Upstream BTC price endpoint | Coindesk public API |
| `MIN_DEPOSIT_USD` / `MAX_DEPOSIT_USD` | Deposit bounds | 20 / 10000 |

## CLI Utilities

Run the investment threshold checker via either command:

```bash
flask --app app check-investments
# or
python manage.py sell_or_not
```

The command fetches the current BTC price and prints alerts when simulated
investments cross their configured lower/upper limits.

## Development Notes

  to start over.
- Emails, Stripe payments, and Stormpath have been removed. The app is now
